# Projeto Faculdade - code6 🚀

O **code6** é uma plataforma web voltada para a área de cursos de tecnologia. O site funciona como um espaço prático e intuitivo para ajudar as pessoas a se capacitarem e entrarem no mercado tech. Através de uma interface organizada, o sistema apresenta os cursos e conteúdos de forma clara, facilitando a navegação do usuário do começo ao fim da página.
